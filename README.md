## 🧠 Philosophy: Why Security + Development Together

Most engineers specialize in one lane:

- Developers who don’t understand attack surfaces  
- Security professionals who never built production systems  

I deliberately avoid that split.

### My model:
- **Security leads (≈70%)**
- **Development supports (≈30%)**

Development is not a side hobby here — it is the **attack surface**.

If I can build it:
- I can break it  
- I can secure it  
- I can explain *why* it failed  

That’s the skill modern security teams actually need.
